# Drift Demo Example

This directory is a self-contained Litmus drift example.

## Files
- `litmus.toml` project configuration
- `agent.py` runnable agent entrypoint (`agent:generate_answer`)

## Quick Start
1. `cd examples/drift-demo`
2. Ensure `OPENAI_API_KEY` is set
3. From repo root, run `python examples/drift_example.py`
