# Simple Agent Example

This directory is a self-contained Litmus example.

## Files
- `litmus.toml` project configuration
- `agent.py` runnable agent entrypoint (`agent:my_agent`)

## Quick Start
1. `cd examples/simple-agent`
2. Ensure `OPENAI_API_KEY` is set
3. From repo root, run `python examples/simple_example.py`
